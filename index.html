策略理论与执行规则

纳指100：固定5000基准 + 三项压力机制

纳指保留固定5000基准的四档：≥+1.5% 买2500，-1%~+1.5% 买5000，-2%~-1% 买7000，≤-2% 为场外8000+场内4000候选。40年数据没有推翻5000基准，真正需要控制的是两类行情：连续阴跌时买得不够，连续暴跌时太快消耗弹药。

阴跌补丁：近5日累计≤-3%，且5日内无单日≤-2%，则把原本5000/7000提升到场外8000；不涉及场内，不承担溢价风险。

大跌簇：近5日内第3次出现≤-2%，暂停场内4000候选，只保留场外8000。

滚动预算：5日4万 / 10日7万 / 20日14万；触发时优先削减场内候选。

标普500：轻量化三机制

标普波动低于纳指，场外2000固定不变。跌-1%~-2%时场内候选3000，跌-2%~-3%时场内候选8000，跌≤-3%时场内候选15000。

标普阴跌补丁：近5日累计≤-3%，且5日内无单日≤-2%，总候选提升至5000，即场外2000+场内候选3000。

标普大跌簇：近5日内第3次≤-2%，总候选降至5000。

标普滚动预算：5日3万 / 10日5万 / 20日9万；主要用于限制场内大额候选。

为什么这个方案适合 GitHub Actions + Pages

GitHub Pages 只能展示静态网页，不能长期运行Python；GitHub Actions 可以按计划自动运行Python脚本，生成 data/latest.json 后再部署到 Pages。这样既保留了网页的简单性，又获得了“每天自动计算”的后端能力。
